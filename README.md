# 🎓 에브리타임 강의 리뷰 다차원 군집화 및 특성 태그 도우미

## 📌 프로젝트 소개
본 프로젝트는 '에브리타임'의 대학 강의 리뷰 데이터를 텍스트 마이닝 기법으로 분석하여 강의의 다차원적 특성을 도출하고, 이를 바탕으로 수강 신청 시 직관적인 해시태그를 제공하는 **크롬 확장 프로그램(Chrome Extension)**입니다[cite: 4]. 기존 5점 척도 기반 정량적 평가의 한계를 극복하고, 정성적 서술평에 담긴 학습자의 실제 만족도 요인을 파악하여 데이터 기반의 의사결정을 돕습니다[cite: 4].

## 🔍 주요 분석 및 연구 결과
경희대학교 공과대학 및 소프트웨어융합대학의 강의 리뷰 1,063건을 수집하여 분석을 진행했습니다[cite: 4].

* **강의 특성 군집화 (K-Means & KoSimCSE):** 서술평 데이터를 KoSimCSE 모델로 임베딩한 후, 실루엣 계수를 기반으로 K-means 클러스터링(K=8)을 수행하여 8개의 강의 특성 군집(예: `#학점_주의`, `#강의력_최고`, `#팀플_위주` 등)을 도출했습니다[cite: 4, 12].
* **리뷰 길이와 평점의 상관관계:** 리뷰의 텍스트 길이와 부여된 평점 간에 유의미한 음(-)의 상관관계가 있음을 통계적으로 입증했습니다. 만족도가 낮은 학습자일수록 구체적 비판을 위해 리뷰를 길게 작성하는 경향이 나타났습니다[cite: 4].
* **핵심 만족도 지표 도출:** '설명', '이해', '교수' 등의 키워드가 평점 결정에 가장 큰 영향력을 행사하는 핵심 지표임을 확인했습니다[cite: 4].
* **평점 부여의 비대칭성:** 수강생들이 긍정적/부정적 감정 상태일 때 평점을 부여하는 방식에 통계적으로 유의미한 비대칭성이 존재함을 카이제곱 검정을 통해 검증했습니다[cite: 4].

## 🛠️ 기술 스택 (Tech Stack)
* **데이터 수집:** Python, Selenium, BeautifulSoup, Pandas[cite: 13]
* **데이터 전처리 및 모델링:** Sentence-Transformers (KoSimCSE), Scikit-Learn (K-Means, LightGBM), UMAP, Seaborn[cite: 4, 12]
* **확장 프로그램 개발:** JavaScript, Chrome Extension API (Manifest V3)[cite: 9, 11]

## 📁 주요 파일 설명
* `content.js`: 에브리타임 시간표 페이지의 DOM을 감시(MutationObserver)하고 강의명에 맞춰 태그를 동적으로 주입하는 핵심 로직을 담당합니다[cite: 9].
* `manifest.json`: 크롬 확장 프로그램의 기본 정보와 권한을 정의한 설정 파일(Manifest V3)입니다[cite: 11].
* `lecture_tags.json`: 분석 및 분류 모델(LightGBM)을 통해 최종적으로 예측된 강의별 해시태그 매핑 데이터입니다[cite: 2, 4, 10].
* `khu_all_reviews_accumulated.csv`: Selenium을 활용하여 병합 및 누적 수집된 원본 강의 리뷰 데이터셋입니다[cite: 13].
* `텀프1_2026_06_02버전.pdf`: 본 프로젝트의 상세한 문제 제기, 가설 설정, 분석 방법 및 결과를 담은 최종 학기말 결과 보고서입니다[cite: 4].

## 🚀 기능 및 활용 (크롬 확장 프로그램)
이 확장 프로그램을 브라우저에 개발자 모드로 추가한 뒤 에브리타임 시간표 페이지에 접속하면, 데이터 마이닝을 통해 분류된 강의 특성 태그(예: `#강의력_최고`, `#난이도_높음`, `#꿀강`)가 강의명 옆에 실시간으로 시각화되어 나타납니다[cite: 4, 9]. 정보가 부족한 신설 강의 등은 `#강의평_부족`으로 처리되어 수강생들이 왜곡된 정보를 접할 가능성을 차단합니다[cite: 4].
